# apps

Home repo for Darren's app portfolio: research, plans, and the apps themselves.

## What's here

- `research/` — category comparison, the trend-to-app pipeline plan, the early-adopter niche method, the narrow-niche shortlist, and daily collector counts.
- Strategy doc: [App Development Strategy for a Solo Indie Portfolio](https://claude.ai/code/artifact/c2453557-3c03-4e9a-90b9-46edfbd913d2).

New apps go in their own top-level folder (for example `vending-route/`).

## Related repos

- [darrenzou/app-keyword-tracker](https://github.com/darrenzou/app-keyword-tracker) — daily GitHub Actions collector for App Store and Google Play keyword ranks and top charts.
- [darrenzou/tradeapp](https://github.com/darrenzou/tradeapp) — private net-worth tracker (separate project).

## Ground rules

- Build improved apps from 1-star review gaps, not tweaked copies (App Store rule 4.1).
- Nothing ships to a store without Darren's approval.
- Prefer free tools and data sources.
